# Custom DIW Printer
Direct ink Writing(DIW) is a technology that enables 3d printers to print many gels, solvents, and other liquids instead of normal plastic filaments. Many printers that have this function can cost from $2,000 up to $20,000, so the goal of this project is to make a low-cost, DIY DIW printer.

For more information about the software, go [here](https://eli3162.github.io/diw_printer/firmware)

For more information about the circuit board, go [here](https://eli3162.github.io/diw_printer/pcb)
